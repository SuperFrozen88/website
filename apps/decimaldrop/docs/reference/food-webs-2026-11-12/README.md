## Scope

**Science → Food Chains and Food Webs / Food Web Woods** has 143 original multiple-choice questions across 12 skills and 12 study cards. Each question's `photoNumbers` maps to the page numbers above. Questions are original, not copied from the worksheets. Exact classroom quiz coverage is unconfirmed.

Pages 5–8 contain filled-in answers. They are used as the class's expected content, not as student mastery evidence; no responses were imported into progress. Class classifications that depend on local diets (for example mouse, fish, and turtle as omnivores) are presented as "the class listed…" rather than as universal facts. Arrows in the hand-drawn class web that are hard to read are not used in questions. Procedure quantities such as the 500 mL of soil appear only where they support fair-test reasoning.
